# 교대근무 휴가·대근 데모 상세 사용설명서

이 설명서는 공개 데모를 처음 보는 사용자를 위한 자료입니다. 화면 데이터는 모두 합성이며 실제 저장되지 않습니다.

## 공통 화면

- 상단 `데모 모드`는 운영 서버와 연결되지 않았음을 뜻합니다.
- 주 메뉴에서 `내 근무표`, `전체근무`, `대근`, `일정`, `더보기`를 선택합니다.
- 각 화면 상단에는 화면 목적과 항상 알아야 할 주의사항이 표시됩니다.
- `이 화면 사용법`을 펼치면 작업 순서와 저장 결과를 확인할 수 있습니다.

## 1. 내 근무표

목적: 본인의 기본 근무와 휴가·대근·교육·지원 기록을 날짜별로 확인합니다.

1. 달력에서 날짜를 선택합니다.
2. 선택한 날짜의 기본 근무와 등록 기록을 확인합니다.
3. `휴가 입력` 또는 `근무변경 입력`을 누르면 데모 입력창이 열립니다.
4. 휴가 날짜 단위는 `일`, 대근·지원 시간 단위는 `시간`입니다. 예: 종일 휴가 1일, 주간 대근 12시간.
5. 데모의 저장 버튼은 서버에 기록하지 않고 저장 결과 안내만 보여 줍니다.

## 2. 전체근무

목적: 같은 기간의 A/B/C/D조와 상주 근무를 비교합니다.

- `주`는 주간, `야`는 야간, `휴`는 휴무입니다.
- `상주A/B`는 서로 다른 격주 금요일 휴무 예시입니다.
- `미1`은 해당 날짜·근무에 아직 1명이 충원되지 않았다는 뜻입니다.
- 실제 근무자의 휴가 사유나 개인 메모는 전체 화면에 표시하지 않습니다.

## 3. 대근

목적: 근무 공백을 채울 대근 수요와 지원·확정 상태를 확인합니다.

- `대근 수요`: 특정 날짜·조·주야 근무에 필요한 추가 인원입니다.
- `미충원`: 필요 인원에서 확정 인원을 뺀 남은 인원입니다.
- `지원`: 근무 의사를 등록한 상태이며 확정과 다릅니다.
- 지원 버튼을 누르면 화면에서 지원/취소 상태가 바뀌지만 서버에는 저장되지 않습니다.
- 실제 앱에서는 휴가자가 대근 필요를 선택하고 그날이 기본 근무일일 때 자동 수요가 생성됩니다.

## 4. 일정

목적: 교육·지원·회사 일정과 중요 공지를 확인합니다.

- 기간 단위는 날짜입니다. 예: 2026-08-27~2026-08-28.
- 필요 인원을 1명 이상 지정한 일정은 대근 수요와 연결될 수 있습니다.
- 일반 안내는 저장 가능 상태이고, 필수값 누락은 저장을 막는 오류입니다.

## 5. 더보기와 역할

- 관리자: 계정, 권한, 조 이동, 대리입력과 운영 복구를 담당합니다.
- 편집자: 공지와 대근 운영을 도울 수 있지만 계정·권한은 변경하지 못합니다.
- 작업자: 본인 기록을 관리하고 공용 대근 수요를 봅니다.
- 배우자: 공유받은 일정만 읽으며 대근 수요·개인 메모·관리 기능은 볼 수 없습니다.

`조 이동 적용일`은 새 조 규칙이 시작되는 첫날입니다. 과거 기록을 지우지 않고 적용일부터 기본 근무표만 달라집니다.

## 오류·정정·복구

- `주의 · 저장 가능`: 확인이 필요하지만 저장할 수 있습니다.
- `저장 불가 · 입력 수정 필요`: 날짜·인원·시간 등 필수값을 고쳐야 합니다.
- 데모 입력은 새로고침하면 모두 초기화됩니다.
- 운영 앱에서는 잘못 저장한 기록을 해당 목록의 수정·취소·삭제 절차로 정정해야 합니다.

## 안전·정확도 한계

- 데모는 기능 설명용이며 근로시간·급여·인사 판단에 사용하지 않습니다.
- 합성 일정과 근무 규칙은 실제 회사 기준이 아닙니다.
- 운영 기능·권한·백업 복구는 공개 데모에서 실행할 수 없습니다.
